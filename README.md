## 📖 О проекте

**Рунический Став** — это нативное Android-приложение, объединяющее строгие принципы исторической скандинавской традиции (Гальдрабук, Хульдский манускрипт, Старший Футарк) и современные алгоритмы процедурной векторной геометрии.

Приложение позволяет создавать как аутентичные гальдраставы (Вегвизир, Эгисхьяльм, Шлем Ужаса), так и персональные вязаные руны на основе намерений или имён, генерировать высококачественные эскизы и трафареты для татуировки, примерять их на теле с помощью камеры и изучать древнюю символику Севера.

## ✨ Ключевые возможности

### 1. 🧭 Процедурный конструктор ставов (`BuilderScreen`)
- **Радиальная симметрия:** Генерация 4, 6 или 8-лучевых ставов с адаптивным распределением ветвей.
- **Вязаные руны (Bindrunes):** Выбор и гармоничное комбинирование рун Старшего и Младшего Футарка на осях.
- **Сакральная геометрия:** Трикветры, Валькнут, Солнечный крест, ромб Ингуз, ядро Агисхьяльма.
- **Наконечники (Finials):** Трезубцы, развилки ворона Одина, стрелы Тюра, круги и дотворки, солнечные спирали.
- **Защитные насечки:** Рассчитанные микро-насечки на несущих стеблях для магической защиты.

### 2. 🎨 Студия тату-эскиза и кастомизатор (`SketchScreen`)
- **7 уникальных визуальных стилей:**
  - 👑 **Сакральное Золото:** Небесные орбиты, астролябия и сияющие золотые узлы.
  - ⚡ **Тату-Блэкворк:** Чёткая тату-графика, акцентные ромбы на внешних полюсах, плотный штрих.
  - 🪽 **Серебро Валькирий:** Тончайшая лунная платина и морозное сияние севера.
  - 🛡️ **Агисхьяльм (Шлем Ужаса):** Исландская традиция охранных ставов с кольцом Футарка.
  - 🪨 **Резьба по камню:** Рельефные фасеты и сколы, имитирующие рунические камни Еллинге.
  - 🌿 **Кельтская вязь:** Переплетающиеся ленты и узлы.
  - ✨ **Сакральный Дотворк:** Мягкие точечные градиенты и растушёвка.
- **Трафаретный режим (Stencil Mode):** Чистый монохромный векторный контур с повышенным контрастом специально для термопринтеров и трансфера на кожу.
- **Экспорт в SVG и 4K PNG:** Чистые математические векторные кривые без потери качества в любом масштабе.

### 3. 🪄 Магическая анимация начертания (`RunicCanvas`)
- Реалистичное пошаговое проявление става:
  1. Восход центральной энергии и световых лучей.
  2. Начертание несущих лучей с эффектом **огненной искры резца** на конце линии.
  3. Проявление сакральных знаков и защитных насечек.
  4. Формирование пояса Футарка и орнаментальной рамы.
- Интерактивный перезапуск анимации в одно касание.

### 4. 🪞 Примерка на теле / AR-моделирование (`TryOnScreen`)
- Предварительный просмотр эскиза на коже в реальном времени через камеру или на фото-манекене.
- Полное управление жестами: перемещение, масштабирование pinch-to-zoom, поворот двумя пальцами.
- Режимы наложения (Multiply, Screen, Soft Light) и ползунок прозрачности для реалистичной интеграции с тоном кожи.

### 5. ✍️ Именной став (`NameStaveScreen`)
- Корректная фонетическая транслитерация кириллических и латинских имен в руны Старшего и Младшего Футарка.
- Превращение рунического ряда имени в замкнутый сакральный став-оберег с толкованием энергетики.

### 6. 🔮 Аутентичное гадание на рунах (`DivinationScreen`)
- Расклады:
  - **Руна Одина:** Одиночный ответ на насущный вопрос.
  - **Три Норны (Урд, Верданди, Скульд):** Прошлое, настоящее, будущее.
  - **Крест Стихий:** Комплексный анализ ситуации.
- Прямое и перевёрнутое положение рун, глубокие психологические и эзотерические толкования.

### 7. 📖 Энциклопедия рун (`EncyclopediaScreen`)
- Полный справочник всех 24 рун Старшего Футарка:
  - Названия, значения, рунические поэмы (англосаксонская, норвежская, исландская).
  - Разделение по Аттам (Фрейи, Хеймдалля, Тюра).
  - Практическое применение в магии и амулетах.

### 8. 🏛️ Библиотека исторических гальдраставов (`LibraryScreen`)
- Собрание аутентичных символов из старинных исландских гримуаров:
  - *Vegvísir* (Рунический компас путеводителя).
  - *Ægishjálmr* (Шлем благоговейного страха).
  - *Kaupaloki* (Для удачи в торговле и делах).
  - *Hræthigaldur* (Оберег от врагов и иллюзий).

### 9. 💾 Локальная база данных и избранное (`FavoritesScreen`)
- Сохранение созданных ставов в локальной базе данных **Room DB** (SQLite).
- Полная автономность: 100% функционала доступно **оффлайн** без интернета.

## 🏛 Архитектура и стек

Проект разработан в соответствии с современными стандартами Android Architecture (MVI / MVVM + Clean Architecture):

```
app/src/main/java/com/example/
├── data/
│   ├── catalog/         # Каталог исторических ставов и рун
│   ├── local/           # Room Database, DAO, Entities, DataStore
│   ├── model/           # Доменные модели (Rune, StaveConfig, StaveRecord)
│   ├── repository/      # Репозитории доступа к данным
│   └── translit/        # Фонетическая транслитерация в руны
├── engine/
│   ├── OrnamentGeometry.kt   # Алгоритмы сакральной геометрии, рамок и финиалей
│   ├── StaveComposer.kt      # Математическая модель компоновки и осей става
│   ├── StaveInterpretation.kt# Генерация толкований энергетики ставов
│   └── SvgStaveRenderer.kt   # Векторный рендерер SVG и программный Canvas рендерер
└── ui/
    ├── components/      # RunicCanvas, контроллеры, селекторы параметров
    ├── nav/             # Type-safe навигация Compose Navigation
    ├── screens/         # Экраны приложения (Builder, Sketch, TryOn, Divination и др.)
    ├── theme/           # Material 3 дизайн-система, шрифты, цветовые схемы
    └── viewmodel/       # StateFlow ViewModels
```

### Технологический стек:
- **Язык:** Kotlin 2.0+ (100%)
- **UI:** Jetpack Compose (Material 3)
- **Графика и рендеринг:** Процедурный `Canvas` (Compose), Android `android.graphics.Canvas`, генератор стандартизированного XML/SVG
- **База данных:** Room Database + KSP
- **Асинхронность:** Kotlin Coroutines & `StateFlow` / `SharedFlow`
- **Навигация:** Navigation Compose с type-safe маршрутами
- **Архитектура:** Unidirectional Data Flow (UDF), ViewModel

## 🚀 Сборка и установка

### Требования:
- Android Studio Ladybug (2024.2.1+) или новее
- JDK 17 или 21
- Android SDK 34/36
- Устройство с Android 7.0 (API 24) или выше

### Сборка через Gradle:
```bash
# Клонирование репозитория
git clone https://github.com/your-username/runic-stave.git
cd runic-stave

# Сборка Debug APK
./gradlew assembleDebug

# Запуск локальных тестов
./gradlew testDebugUnitTest
```

### Автоматическая сборка в GitHub Actions (CI/CD):
В репозитории настроен готовый рабочий процесс [`.github/workflows/build-apk.yml`](.github/workflows/build-apk.yml):
- **Триггеры:** Автоматический запуск при каждом Pull Request или Push в ветки `main` и `master`, а также вручную (`workflow_dispatch`).
- **Действия:** Прогон Unit-тестов, компиляция Debug APK на Ubuntu Runner (JDK 17).
- **Артефакт:** Готовый APK-файл автоматически прикрепляется к отчёту пайплайна в разделе **Artifacts** (`runic-stave-debug-apk`).

## 🛠 Для разработчиков

- **Математика штрихов:** Все штрихи става типизированы (`isStem`, `isOuterPole`, `isHairlineGuide`). Это позволяет гибко настраивать толщины и не перегружать центр деталями.
- **Единый источник рендеринга:** Логика в `RunicCanvas.kt` (интерактивный Compose Canvas) и `SvgStaveRenderer.kt` (чистый SVG-генератор и экспорт) строго синхронизирована.
- **Безопасность данных:** Приложение не требует доступа к сети, не собирает аналитику и хранит все эскизы локально на устройстве пользователя.
